MoreContext usa dos licencias: una para el texto y otra para el código. La idea es sencilla: puedes usar casi todo lo que hay aquí, también en proyectos comerciales, siempre que digas de dónde viene.

## Contenido: CC BY-SA 4.0

Los textos, tablas y diagramas se publican con la licencia [Creative Commons Atribución-CompartirIgual 4.0 Internacional](https://creativecommons.org/licenses/by-sa/4.0/deed.es).

**Puedes:**

- Copiar y redistribuir el contenido en cualquier medio o formato.
- Adaptarlo: traducirlo, resumirlo, mezclarlo con lo tuyo o usarlo en una formación.
- Hacer todo lo anterior con fines comerciales.

**Con dos condiciones:**

- **Atribución.** Indica que viene de MoreContext, enlaza la página original y la licencia, y di si has hecho cambios.
- **Compartir igual.** Si publicas una adaptación, debe llevar la misma licencia o una compatible.

### Cómo atribuir

Basta con una línea cerca del contenido reutilizado:

```text
Basado en «Uso de herramientas», de MoreContext (https://morecontextai.com/docs/herramientas/uso-de-herramientas/), CC BY-SA 4.0. Adaptado.
```

Si no has cambiado nada, quita «Adaptado».

## Código: MIT

Los fragmentos de código de las lecciones, docs, recetas y sistemas, y el código del sitio web, se publican con licencia MIT. Puedes usarlos en tus proyectos, también cerrados o comerciales, sin pedir permiso.

La licencia MIT pide conservar el aviso de copyright y de licencia en copias sustanciales del código. Para un fragmento de unas líneas copiado en tu proyecto, un comentario con el enlace a la página es suficiente y se agradece.

```python
# Adaptado de https://morecontextai.com/recetas/reintentos-y-limites-de-tasa/ (MIT)
```

## Lo que no se licencia

El nombre **MoreContext**, el logotipo y el icono no entran en ninguna de las dos licencias. Puedes mencionarlos para atribuir o para hablar del proyecto. No los uses para presentar un producto, un curso o una web como si fueran de MoreContext o estuvieran respaldados por el proyecto.

## Cómo citar MoreContext

Para un trabajo, un artículo o unos apuntes, usa este formato:

```text
MoreContext. «Título de la página». https://morecontextai.com/ruta/de/la/pagina/. Consultado el AAAA-MM-DD.
```

Si usas BibTeX:

```text
@misc{morecontext,
  title        = {MoreContext: más contexto, menos ruido},
  howpublished = {\url{https://morecontextai.com}},
  note         = {Consultado el AAAA-MM-DD}
}
```

Las páginas se actualizan. Pon siempre la fecha de consulta.
