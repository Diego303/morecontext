## Receta corta: cachea el prefijo que se repite

Si cada petición manda el mismo prompt de sistema largo o el mismo documento, estás pagando por procesarlo una y otra vez. El [[glosario/prompt-caching|prompt caching]] guarda ese prefijo y las siguientes peticiones lo leen de caché, que cuesta bastante menos y responde antes.

Marca el último bloque fijo con `cache_control`:

```python title="cache.py"
import anthropic

MODEL = "claude-sonnet-5-5"
client = anthropic.Anthropic()

manual = open("manual.md", encoding="utf-8").read()

resp = client.messages.create(
    model=MODEL,
    max_tokens=1024,
    system=[
        {"type": "text", "text": "Respondes dudas usando solo el manual adjunto."},
        {"type": "text", "text": manual, "cache_control": {"type": "ephemeral"}},
    ],
    messages=[{"role": "user", "content": "¿Cómo restablezco la contraseña?"}],
)

# la primera vez escribe en caché; las siguientes, dentro del TTL, leen de ella
print(resp.usage.cache_creation_input_tokens, resp.usage.cache_read_input_tokens)
```

Tres cosas que conviene saber:

- La caché dura cinco minutos por defecto y se renueva cada vez que se usa.
- Se cachea en orden: herramientas, sistema y mensajes. Si cambias algo antes del punto de corte, la caché no sirve.
- Hay un mínimo de tokens para cachear que depende del modelo. Consulta la [documentación oficial](https://platform.claude.com/docs).
